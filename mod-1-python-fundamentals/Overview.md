# Mod 1 - Python Fundamentals

From data types and variables to lists and iteration, the skills you will learn in this module can be found in any programming language. In this module, we'll learn the particular syntax for Python!

By the end of this module, you will be able to write a Python program that takes input from a user, stores data in lists and dictionaries, makes decisions with conditionals, repeats work with loops, and is organized into modules that each do one job. You will also be able to read a program somebody else wrote, predict what it does, and check your prediction. The module ends with the CLI application project and the Mod 1 proctored hand-coding assessment.
